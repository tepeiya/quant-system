🔄 数据流 (交易时段)
① 数据层(data_global/data_prod) → ② 策略引擎(daily_signal/向量/动量) → ③ 风控(risk_manager/止损) → ④ 交易执行(paper_trader/Alpaca)
日内独立流: intraday(扫描信号) → intraday_trader(风控) → Alpaca(下单)
盘中: daemon守护进程每15分钟循环 + 止损监控持续运行 → push_notify推送通知
收盘后: 权益记录 → 推送日报 → config_db自动备份 → 缓存检查
